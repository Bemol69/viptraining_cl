# VIP Training Gym

Sitio web estático de VIP Training Gym (Portugal 681, Santiago). HTML + CSS + JS, sin proceso de compilación.

- `index.html` — página principal
- `styles.css` — estilos (tema neón, responsive)
- `app.js` — animaciones (GSAP + ScrollTrigger + Lenis desde CDN), estado abierto/cerrado en hora de Santiago, historias, coaches
- `img/` — fotos en WebP tomadas del Instagram @viptraining_cl

Despliegue en Vercel: importar el repo, framework **Other**, directorio raíz del proyecto.
